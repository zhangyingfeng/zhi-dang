知档

本地归档你的知乎回答和文章

「知档」即知乎作者归档。一个安全、开源的内容导出工具，方便作者把知乎上自己的内容归档导出为 Markdown、JSON 和本地图片。

下载 · macOS（Apple Silicon） 在 GitHub 查看源码

版本与更新记录见 GitHub Releases · 仅 macOS Apple Silicon · 首次打开需在「系统设置 → 隐私与安全性」里手动允许一次（图文教程）

从一个很具体的问题开始

作者在内容平台上长期创作之后，如何把自己的作品完整、安全地保存下来，并继续由自己控制。

知档的回答是：把作者自己的知乎创作，转换成开放、可读、可迁移、由作者自己保管的本地归档。

知档不是爬虫，是用户授权的归档工具

知档不抓取知乎，也不采集别人的内容——它只在你本人登录之后，把你自己账号下的回答和文章搬到你自己的电脑上。没有你的登录、没有你的操作，知档什么也拿不到。这是理解下面所有设计和边界的前提。拿"大规模爬虫式工具"做对比，一眼就能看清楚：

问题大规模爬虫式工具现在的知档
抓别人发布的内容经常不允许——只导出当前登录账号本人的回答和文章
聚合整个平台的数据是否——每次只处理你自己这一个账号
获取评论者、粉丝、关注关系等他人资料经常明确不获取
把抓到的数据公开重新提供给别人是否——导出结果只留在你自己电脑上
替代平台本身的浏览服务可能基本不会——只做备份，不做内容消费产品
用户授权方式不一定，常靠密码/Cookie 池本人在登录窗口正常登录
遇到验证码常见的绕过对象交给你本人完成，不绕过
代理池 / 账号池常见明确不用
数据是否经过开发者的服务器常见没有——本地直连知乎，本地写文件
保存位置开发者的云端数据库你自己电脑上的文件夹

一句话总结：知档只做"帮你把自己的账号搬到自己的硬盘"这一件事，凡是会让它变成一个抓取工具或云服务的做法，都不在范围内。

知档的产品边界（这些不是没做完，是刻意不做）

  • 从归档生成网站，以及网站托管、域名、DNS

    发布是另一件事，混进"归档"这层会让它变得不稳定，交给独立项目做。

  • 内容编辑、草稿、版本历史

    知档存的是已发布内容的忠实副本，不是创作工具。

  • AI 分类、摘要、检索、个人写作模型

    这类功能依赖持续变化的模型和算法，知档想保持的是"很多年后打开还能用"的稳定数据层，两种目标放在一起会互相拖累。

  • 云同步、多设备账号体系

    一旦加云同步，"内容不经过任何服务器"这条前面所有的承诺就不成立了。

这是独立开发的非官方项目，与知乎不存在隶属、合作、授权或认可关系；目前只在 macOS（Apple Silicon）上完整测试，使用免费 ad-hoc 签名，首次打开需在系统设置里手动允许一次。详见 免责声明 · 可接受使用。

你会得到什么

导出结果是一个普通的本地文件夹，可以直接读、备份、迁移到自有网站。index.json 和 Markdown 被当作长期数据格式来维护。

Markdown 正文 index.json 索引 export-report.json 报告 本地化图片 
导出目录/
├── answers/           # 每条回答一个 Markdown 文件
├── articles/          # 每篇文章一个 Markdown 文件
├── images/            # 正文里的图片，全部下载到本地
├── index.json         # 全部内容的结构化索引（公开 schema）
├── export-report.json # 总数 / 分页 / 去重 / 失败的完整报告
└── README.md          # 这份导出的说明

每个条目保留原文链接、创建与更新时间、问题 ID、点赞与评论数、封面等元数据。接口报告总数、分页实际返回数、去重后的唯一数会被分别记录；无法解释的差异会给出完整性警告，而不是静默生成错误数据。

怎么用

独立桌面应用，不需要安装 Node.js、Chrome 或任何开发工具。

1

下载并打开

从 GitHub Releases 下载 .dmg，拖进「应用程序」打开。打开后直接是导出设置界面。

2

登录知乎

点「开始登录」，在弹出的独立窗口里正常登录（扫码、验证码或密码）。登录信息只留在本机。

3

选目录，导出

确认保存位置，点「开始导出」。每一项的进度都能看到，可以随时暂停、跳过某一项；完成后显示汇总，并可一键在访达中打开结果。

设计原则

正因为知档的定位是「用户授权的归档工具」，无论它发展到什么程度，都保持以下原则。

平台独立

知乎是当前的内容来源，但数据模型不永远绑定于某个平台的页面结构。

本地优先

作者应能取得自己的完整数据，并能在没有任何云服务的情况下继续使用。

安全隐私

登录信息、Cookie 和导出内容默认只保存在本机，不自动上传；不加入遥测、远程日志或用户内容上传。

开放格式

内容和元数据优先采用公开、可迁移的格式，不制造新的平台锁定。

隐私

这是知档最在意的一层，也是它和「一键搬运」类工具的根本区别。

  • 应用在你自己的电脑上运行，本地服务只监听 127.0.0.1。
  • 在应用内置的登录窗口里直接登录知乎，不需要在表单、终端或配置文件里填密码或 Cookie。
  • 登录会话由系统自带的 WebView 管理（macOS 上是 WKWebView），本应用的后端服务不接触、不读取。
  • 回答、文章和图片只写入你指定的本地目录。
  • 不包含遥测、分析、广告、远程日志或开发者服务器上传。
  • 点「退出登录」即可清除会话；删除导出目录即可清除导出内容。
