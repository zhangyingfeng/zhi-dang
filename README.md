# 知档

「知档」，即知乎作者归档。一个安全、开源的内容导出工具，方便作者把知乎上自己的内容归档导出为 Markdown、JSON 和本地图片。

「知档」从一个很具体的问题开始：作者在内容平台上长期创作之后，如何把自己的作品完整、安全地保存下来，并继续由自己控制。

「知档」的回答是：**把作者自己的知乎创作，转换成开放、可读、可迁移、由作者自己保管的本地归档。**

## 知档不是爬虫，是用户授权的归档工具

「知档」不抓取知乎，也不采集别人的内容——它只在你本人登录之后，把**你自己**账号下的回答和文章搬到**你自己**的电脑上。没有你的登录、没有你的操作，知档什么也拿不到。这是理解下面所有设计原则和使用边界的前提。

拿"大规模爬虫式工具"做对比，边界一眼就能看清楚：

| 问题 | 大规模爬虫式工具 | 现在的知档 |
|---|---|---|
| 抓别人发布的内容 | 经常 | **不允许**——只导出当前登录账号本人的回答和文章 |
| 聚合整个平台的数据 | 是 | **否**——每次只处理你自己这一个账号 |
| 获取评论者、粉丝、关注关系等他人资料 | 经常 | **明确不获取** |
| 把抓到的数据公开重新提供给别人 | 是 | **否**——导出结果只留在你自己电脑上 |
| 替代平台本身的浏览服务 | 可能 | **基本不会**——只做备份，不做内容消费产品 |
| 用户授权方式 | 不一定，常靠密码/Cookie 池 | **本人在登录窗口正常登录** |
| 遇到验证码 | 常见的绕过对象 | **交给你本人完成，不绕过** |
| 代理池 / 账号池 | 常见 | **明确不用** |
| 数据是否经过开发者的服务器 | 常见 | **没有**——本地直连知乎，本地写文件 |
| 保存位置 | 开发者的云端数据库 | **你自己电脑上的文件夹** |

一句话总结：知档只做"帮你把自己的账号搬到自己的硬盘"这一件事，凡是会让它变成一个抓取工具或云服务的做法，都不在范围内。详见 [DISCLAIMER.md](docs/DISCLAIMER.md) 和 [ACCEPTABLE_USE.md](docs/ACCEPTABLE_USE.md)。

这是独立开发的非官方项目，与知乎不存在隶属、合作、授权或认可关系。使用者有责任遵守适用法律、著作权规则和平台条款。开发计划见 [ROADMAP.md](docs/ROADMAP.md)。

## 设计原则

正因为知档的定位是"用户授权的归档工具"，无论它发展到什么程度，都保持以下原则：

- **平台独立**：知乎是当前的内容来源，但数据模型不应永远绑定于某个平台的页面结构。
- **本地优先**：作者应能取得自己的完整数据，并能在没有任何云服务的情况下继续使用。
- **安全隐私**：登录信息、Cookie 和导出内容默认只保存在本机，由作者控制，不自动上传；不加入遥测、远程日志或用户内容上传。
- **开放格式**：内容和元数据优先采用公开、可迁移的格式，不制造新的平台锁定。

## 如何安装使用？

「知档」是独立桌面应用，不需要安装 Node.js、Chrome 或任何开发工具（当前只提供 macOS，Apple Silicon）。

下载、安装和每一步操作见[图文教程](docs/GETTING_STARTED.md)。

本项目为独立实现，不包含或派生自上述项目的源代码。上述项目各自适用其原有许可证。

本项目同时直接使用 Tauri、Express、Turndown、Zod 等开源依赖，桌面端打包使用 Bun 把后端编译为独立可执行文件。
具体版本见 `package.json`、`package-lock.json` 和 `src-tauri/Cargo.toml`。
