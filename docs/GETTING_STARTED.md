# 使用教程

这份教程按实际操作顺序，用截图说明从下载到导出完成的完整流程。

## 1. 下载和安装

从 [GitHub Releases](https://github.com/zhangyingfeng/zhi-dang/releases) 页面下载最新版本的安装包。当前只提供 macOS（Apple Silicon）版本，安装包是一个 `.dmg` 文件。

下载后双击打开 `.dmg`，把"知档"拖进"应用程序"文件夹，再从"应用程序"或启动台打开。

## 2. 首次打开

第一次打开时，因为应用尚未完成 Apple 开发者签名，macOS 会先提示"无法验证开发者"：

![Gatekeeper 警告：Apple 无法验证"知档.app"是否包含可能危害 Mac 安全或泄漏隐私的恶意软件](images/01-gatekeeper-warning.jpg)

点"完成"关掉这个提示，然后打开"系统设置 → 隐私与安全性"，滚动到底部会看到一条允许打开的选项：

![系统设置里的"仍要打开"按钮](images/02-allow-in-settings.jpg)

点"仍要打开"，会再弹一次确认框，点"仍要打开"确认：

![二次确认框："打开知档.app？Apple 无法验证其是否包含可能危害 Mac 安全或泄漏隐私的恶意软件。除非你确定其来源可靠，否则请勿打开"](images/03-confirm-open.jpg)

这一整套流程只需要做一次。之后应用会正常启动。

## 3. 登录知乎

打开后直接就是导出设置界面。未登录时下方的选项都是禁用状态，右上角是唯一能点的"开始登录"：

![未登录状态，标题为"登录知乎导出"，右上角"开始登录"按钮为主按钮样式，下方保存位置、下载正文图片、开始导出均为禁用状态](images/04-login-required.jpg)

点击后会弹出一个独立窗口，在其中正常登录知乎（扫码、验证码或密码登录都可以）：

![知乎登录窗口，标题栏显示"知档 - 登录知乎"](images/05-zhihu-signin.jpg)

登录成功后，这个窗口会自动提示可以关闭：

![登录窗口顶部出现绿色横幅："登录成功，可以关闭此窗口"](images/06-login-success.jpg)

回到主窗口，界面已经自动变成可用状态——标题变为"欢迎 [昵称]，可以下载"，保存位置默认按账号自动命名（不同账号登录会用不同的默认目录，避免混在一起）：

![已登录状态，标题栏显示欢迎信息，右上角"退出登录"按钮，保存位置、下载正文图片、开始导出均已启用](images/07-ready-to-export.jpg)

只要没有点过"退出登录"，下次重新打开应用会记住这次登录，直接跳到这个可用状态，不需要再登录一次。

## 4. 开始导出

确认保存位置（默认即可，也可以点"浏览…"改成其他目录），点击"开始导出"。导出过程中，相关设置会被禁用，避免中途误改；一开始是先获取回答/文章列表：

![导出进行中，状态区域显示"已获取 80 个回答"，导出按钮显示"导出中…"且已禁用](images/08-exporting.jpg)

## 5. 查看和管理导出进度

列表获取完之后，状态区域下方会出现一个任务列表，列出了这次导出发现的每一篇回答/文章——一开始就会全部出现（不用等下载完才看到），每一项显示自己的状态：未开始、进行中、完成、失败或已跳过。状态区域右侧有"暂停"/"继续"按钮，可以随时暂停，不会丢失已经完成的部分；还没开始处理的项，右侧会有一个"跳过"按钮：

![任务列表：第一项已完成（绿色），暂停按钮显示"继续"，其余项显示"跳过"按钮](images/09-task-list-paused.jpg)

如果某几项的正文内容完全一样（比如同一篇文章既发了回答又发了文章），会标一个"疑似重复"的提示——这只是提醒，不会自动处理：

![两行标有橙色"疑似重复"徽章的列表项](images/10-duplicate-flag.jpg)

点"跳过"处理重复项——留一份、跳过另一份，跳过的行会变暗并加删除线：

![两行"疑似重复"的列表项已跳过，标题变暗并显示删除线](images/11-duplicate-skipped.jpg)

点每一行右侧的展开按钮，还能看到这一项的图片下载和写入文件两个子步骤各自的状态，图片可以展开看到每一张的下载情况；开了"下载正文图片"的话，展开后图片那一行还有单独的"跳过图片"按钮，只跳过图片、正文照常保存。

如果导出中途关闭了应用（或者不小心退出），重新打开后把保存位置指向**同一个目录**再次点"开始导出"，已经完成的部分不会重新下载，只会继续处理没完成的部分。

## 6. 查看结果

导出完成后会显示汇总信息，同时"开始导出"按钮会变成"在访达中显示"（同一个按钮换了文字和功能，不是新出现一个按钮）。如果这时候改了保存位置准备导出到别的地方，这个按钮会自动变回"开始导出"。

系统这时候还会弹一条通知提醒导出完成（内容和状态区域显示的汇总信息一样），方便导出耗时比较久、没有一直盯着窗口的时候知道什么时候结束。首次导出会请求一次通知权限，声音是否播放跟着 macOS 自己的通知设置走，应用不会额外放提示音。

![导出完成，状态区域显示"完成：119 个回答，49 篇文章；已去重 20 条重复记录"，进度 168/168，"在访达中显示"按钮为主按钮样式](images/12-export-done.jpg)

点"在访达中显示"，会在 Finder 里直接定位到导出目录：

![Finder 窗口，选中的导出目录里包含 answers、articles、images 文件夹，以及 export-report.json、index.json、README.md](images/13-reveal-in-finder.jpg)

导出结构和各文件的说明见[开发者文档的"导出结构"一节](DEVELOPMENT.md#导出结构)。
